## Реализованный функционал

1. **Ввод/вывод данных:** Реализовано диалоговое окно `prompt` для индивидуального приветствия пользователя и всплывающие окна `alert` для вывода итоговых расчетов
2. **Исходный массив данных:** Создан массив `waterConsumption` из 7 элементов, отражающий ежедневное потребление воды в литрах.
3. **Обязательные функции:**
   * Поиск максимального значения в массиве (`findMax`).
   * Фильтрация дней, когда норма была превышена (> 3 литров), с помощью метода `.filter()`.
   * Подсчёт общего количества выпитой воды за неделю с помощью метода `.reduce()`.
4. **Алгоритмы ветвления и циклов:** С помощью цикла `for` и условия `if` вычисляется количество дней с низким уровнем потребления жидкости (<= 1.5 л) и рассчитывается их процентное соотношение от всей недели.
5. **Дополнительное задание:** Реализован расчёт среднего арифметического значения потребления воды с выводом персональной рекомендации в консоль браузера.
